网页 / 自建 agent：引入 SDK，添加 <petrel-background>。React、Vue 和普通 HTML 共用同一个组件。

已有 agent 网页：加载项目内的 Chrome / Edge 扩展，点击图标手动开启装饰层。它在页面上方以低亮度显示，中央区域留空。

当前 Codex 桌面：可在聊天侧栏运行此预览。目前没有验证到整块聊天动态背景的扩展接口；本项目未改动客户端。
