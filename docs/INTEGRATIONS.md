# 接入边界与后续适配

| 宿主 | 本次实现 | 具体边界 |
| --- | --- | --- |
| 普通 HTML / 自建 agent UI | 可直接嵌入的 SDK / Web Component，已浏览器测试 | 宿主需提供尺寸和层级 |
| React / Vue | 共用浏览器 SDK 的生命周期接入方法 | 未创建额外的 React / Vue 包，未运行对应框架项目 |
| Chromium / WebView | 与浏览器同一组件合同 | 需要宿主允许注入本地脚本；本次未验证所有 WebView 产品 |
| Chrome / Edge 的现有 agent 网页 | 手动启用的 MV3 装饰层 | 本次在本地网页测试脚本开关；具体第三方站点效果尚未逐站验证 |
| 当前 Codex 桌面 | v0.2.0 可安装插件，内置技能启动本地侧栏预览、调节主题/鸟群、复制 SDK 接入网页 | **没有替换主聊天背景**；插件技能需安装后在新聊天加载 |
| Cursor / Antigravity / 其他原生客户端 | 可复用渲染代码，但未提供宿主适配器 | 需要分别确认支持的 UI 扩展能力，不能声称通用支持 |
| 终端 / CLI agent | 未实现 | 字符终端不使用 HTML Canvas，需另做终端渲染器 |

## 适配器合同

一个新的宿主适配器需要：创建有尺寸的 Canvas 或 `<petrel-background>`；把真实 agent 状态映射至 `idle/working/waiting/done`；保持聊天正文、代码和输入区可读；卸载时调用 `destroy()` 或移除组件。渲染引擎无需修改。

当前不提供补丁 app.asar、开启调试端口、读取聊天内容或修改客户端二进制的安装流程。若未来宿主提供正式的自定义背景入口，可以让适配器加载现有 `dist/sdk`。如果选择非官方接入方案，需另行检查本机版本、可恢复方式，并单独验证实际 UI 效果。
